## Font

Barlow ExtraBold and OFL license downloaded from the Google Fonts upstream:
https://github.com/google/fonts/tree/main/ofl/barlow .
The BlockResin family is isolated to this feature.

Generated with the built-in image generator, using `02-fresh-resin-lab.png` as the composition/material reference. UI text, scores, game values and controls remain native Flutter; only the decorative hero has baked illustrative numbers.
