## Font

DM Serif Display is bundled as QuizDisplay, downloaded from the official Google Fonts repository. License: SIL Open Font License; retained at assets/fonts/DMSerifDisplay-OFL.txt. Body typography reuses the existing Barlow assets.

Source: https://github.com/google/fonts/tree/main/ofl/dmserifdisplay

Artwork is generated, not downloaded stock art. No third-party stock license is claimed. Opaque topic art deliberately includes an architectural niche; trophy, help and leave art are isolated transparent cutouts. Menu uses complete-topic artwork with responsive cropping; small gameplay artwork is generic so it cannot reveal answers.

Runtime decode widths are bounded at 720 px for illustrations and 1080 px for the background. Mockups in this directory are documentation only, not shipped Flutter assets.
